# Repository files

> Reference · [Documentation](../../README.md#documentation)

What the script writes into the Git repository with `argocd.addons.enabled`,
under `argocd.addons.path` (default `clusters/<name>`). How the add-ons work
from Git: [GitOps and add-ons](../explanation/gitops.md). To change them:
[Manage the add-ons in Git](../how-to/manage-addons-in-git.md).

## Files

| File | Content |
|---|---|
| `addons/generated/addons.yaml` | The app-of-apps `addons`: syncs `addons/` recursively |
| `addons/generated/<application.name>.yaml` | The root Application (not with `argocd.application.enabled: false`) |
| `addons/generated/cilium.yaml` | Application: Cilium chart (LAN mode) |
| `addons/generated/argocd.yaml` | Application: Argo CD itself (argo-cd chart) |
| `addons/generated/cert-manager.yaml`, `headlamp.yaml`, `longhorn.yaml`, `metrics-server.yaml`, `monitoring.yaml`, `tuppr.yaml` | Applications of the optional sections |
| `addons/generated/ingress.yaml`, `talos-backup.yaml` | Applications of the topics without a chart |
| `addons/generated/gateway-api.yaml` | LAN mode: Application of the Gateway API CRDs (`cilium.gatewayApiVersion`), never pruned |
| `generated/gateway-api/kustomization.yaml` | its kustomization |
| `generated/<topic>/` | One topic's manifests (`<kind>-<namespace>-<name>.yaml`) and a `kustomization.yaml`; with Secrets, a KSOPS `generator.yaml` and the encrypted `secret-<namespace>-<name>.enc.yaml` |
| `generated/CHECKSUMS` | sha256 of every file above, so the repository can refuse edits by hand |
| `.sops.yaml` | SOPS mode: the recipients, for editing encrypted files by hand |

Every generated file starts with the header `# Generated by deploy-talos.py`.
`destroy` removes the cluster's generated files from the repository.
The script owns `addons/generated/` and `generated/`: a file there it no
longer generates is removed (`addons.content: generate`).

## Topics

| Topic (`generated/<topic>/`) | Synced by | Content |
|---|---|---|
| `ingress` | Application `ingress` | namespace, the [ingress gateway](ingress-gateway.md), its Certificates |
| `cert-manager` | `cert-manager` (second source) | ClusterIssuer `acme` |
| `argocd` | `argocd` (second source) | UI routes, OIDC Secret |
| `headlamp` | `headlamp` (second source) | routes, OIDC Secret; with `oidc.crossplane` the Keycloak client objects |
| `monitoring` | `monitoring` (second source) | Grafana routes, OIDC and admin Secrets; with `oidc.crossplane` the Keycloak client objects |
| `tuppr` | `tuppr` (second source) | `TalosUpgrade talos`, `KubernetesUpgrade kubernetes` |
| `talos-backup` | Application `talos-backup` | namespace, Talos ServiceAccount, CA ConfigMap, CronJob |
| `gateway-api` | Application `gateway-api` | the Gateway API CRDs |

## Argo CD projects

| Applications | Project |
|---|---|
| `addons`, the root Application | `default` |
| `headlamp`, `ingress`, `talos-backup` | `argocd.addons.projects.services` (default `platform-services`) |
| every other generated add-on | `argocd.addons.projects.infra` (default `platform-infra`) |

The projects themselves are AppProjects the repository provides.

## Secrets in Git (SOPS mode)

With `argocd.addons.sopsAgeKeyFile`:

| Secret | File |
|---|---|
| Argo CD OIDC client secret | `generated/argocd/secret-argocd-argocd-keycloak.enc.yaml` |
| Headlamp OIDC settings | `generated/headlamp/secret-headlamp-headlamp-oidc.enc.yaml` |
| Grafana OIDC client secret | `generated/monitoring/secret-monitoring-grafana-oidc.enc.yaml` |
| Grafana local admin | `generated/monitoring/secret-monitoring-grafana-admin.enc.yaml` |
| talos-backup S3 keys | `generated/talos-backup/secret-talos-backup-talos-backup-s3.enc.yaml` |

Only `data`/`stringData` values are encrypted.

## Outside the repository

| Object | Why |
|---|---|
| Secret `argocd/gitops-repository` | the repository credential: Argo CD needs it to read the repository |
| Secret `argocd/sops-age` | the cluster's age key, which decrypts the Secrets above |
| the add-on Secrets, without SOPS mode | created in the cluster by the script |
| CiliumLoadBalancerIPPool `lan`, CiliumL2AnnouncementPolicy `lan` | node layout, changed by `scale` and `longhorn` |
| the first Cilium and Argo CD install | the bootstrap, with Helm; Argo CD adopts them in the same run |
